# Verification Architecture (`docs/verification.md`)

**CELLULOGONIC MECHA `v1.7.0`** combines four independent layers of verification so no single tool, compiler, or kernel acts as an unchecked single point of trust (also see root [`VERIFICATION.md`](../VERIFICATION.md)).

## Layer 1 — Six-Kernel-Check Pure Lean 4.35.0 Specification Verification (`lean/`)
- **Scope:** **78 audited theorems** (`T01`–`T58`, `C59`–`C62`, `NV01`–`NV08`, `AT01`–`AT08`) about the `Spec.lean` model, in **10 proof modules + `Spec.lean` (15 `.lean` files)**. Five statements (`T25`, `T27`, `T40`, `T41`, `T44`) are explicitly annotated arithmetic bookkeeping helpers (`docs/statement-fidelity.md` §2); literal-only conjuncts previously in `T41`, `T54`, `C62`, `NV08` were removed in `v1.7.0`; `T16` includes equality iff `x = y`; `T39`/`T43` include explicit `Nat` non-underflow conservation (+ `Int` companion in `T43`); zero Mathlib, `autoImplicit = false`, `relaxedAutoImplicit = false`, `linter.unusedVariables = true`, `linter.deprecated = true`.
- **Palomar Isolation & Live Elaboration/Tamper Rejection:** `Challenge.lean` imports ONLY pure `Spec.lean`; `Solution.lean` exports the 78 sorry-free proofs; `comparator.json` pins all `78` theorems plus `12` core `Spec.lean` definitions and permitted axioms (`[propext, Classical.choice, Quot.sound]`). Both `scripts/test_lean_negative.py` (`6/6`: 2 false-claim elaboration rejections, live `Spec` `sorry`-tamper, standalone `sorry`, custom `axiom`, `native_decide`) and a CI sorry-tampered `lake comparator --paranoid` failure gate prove the verification gate catches real exploits.
- **Kernel Replay & README Lock:** Ubuntu CI runs **6 kernel checks** (Lean default and paranoid modes + 4 independent checkers: `lean4lean`, `nanoda_bin`, `con-leche`, `con-ron`) under `bubblewrap`, diffs `results/lean4-audit.txt` verbatim against fresh `VerifyAxioms.lean` output, and runs `scripts/check_readme_axioms.py`.

## Layer 2 — Native C11 Falsification, Mutants, Property Testing, Sanitizers & Fuzzing
- **26-Gate + 8-Mutant Suite (`test/test_falsification.c`):** `26 / 26` PASS (`G01`–`G26`), `8 / 8` planted negative mutants (`M1`–`M8`, incl. simulation-level `M3`) caught across Windows x86-64 (`clang 23.1.0 -Werror`), Linux x86-64 (`gcc 13.3.0 -Werror`), and macOS ARM64 (`clang -Werror` in CI), plus 3-module `llvm-nm`/`nm` zero-heap hot-loop symbol verification (`chemoton_physics`, `cellular_world`, `metrology_covi`).
- **Cross-OS / Cross-ISA Bit-Exact Parity:** `SIMD_AVX2` == `SCALAR_REF` == macOS ARM64 (`SHA-256 = 83317026b088e005eda739e0c7180b40d15ef9ac4bf9be2c32b690c6532c9bbe`, 0-bit diff, `0 amu` / `0 uq` drift, `0` allocs).
- **Property-Based Suite (`scripts/prop_check.py`):** `2,720 / 2,720` randomized trials across mathematical laws plus 20 randomized native C11 binary executions.
- **Sanitizers, Fuzzing, Python Oracle & Web Security Suite:** `-fsanitize=address,undefined -fno-sanitize-recover=all` + `clang -DCELL_LIBFUZZER -fsanitize=fuzzer,address,undefined` run in Ubuntu CI; `test/fuzz_cmbin_abi.c` runs `1,000 / 1,000` adversarial `"CMB5"` binary/ABI fuzz cases in every build; `reference/chemoton_oracle.py` + `scripts/verify_oracle_and_stats.py` execute `6,586` exact-rational oracle & `p_Holm <= 0.05` statistical checks; `test/test_web_server.mjs` verifies `13 / 13` Web Observatory HTTP/CSP/CSRF/DNS-rebinding/favicon invariants.

## Layer 3 — Statistical, Bibliographic & Publication Verification
- **Locked Paired Statistics (`N = 24`, seeds `5000..5023`):** Deterministic 10,000-iteration sign-flip permutation test + step-down Holm–Bonferroni FWER across pre-registered `H1`–`H4` (`96/96` wins, `p_Holm = 0.00040 <= 0.05`, `d_z ∈ [1.468, 3.560]`).
- **Live Crossref Title/Author & Retraction Audit & Zero-Overflow Paper Build:** `scripts/check_citations.py` (`v2`) verifies `36 / 36` BibTeX DOIs live against Crossref (`results/citation-audit.json`, `36/36` title & author aligned, `0` retractions); `scripts/build_paper.py` compiles `paper/main.tex` with Tectonic enforcing `0` Overfull `\hbox`/`\vbox`, `0` undefined refs/citations/labels, and clean-room `dist/arxiv_submission.tar.gz` compilation.

## Layer 4 — Repository, Blueprint, FAIR Metadata & Cryptographic Provenance Audit
- **Build Standard v1.2.0 & Schema Validation:** `scripts/Audit-Repo.ps1` / `scripts/audit-repo.sh` verifying `100.0%` Structure / `100.0%` Completion / `100.0%` Core, with `repo.yaml` strictly validated against `repo-standard.schema.json`, plus static Interactive Blueprint built by `scripts/build_blueprint.py`, validated by `scripts/check_blueprint.py`, and published via GitHub Pages (`.github/workflows/pages.yml`).
