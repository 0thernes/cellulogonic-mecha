## 2. Formal Verification Suite (`lean/`)

- `CellulogonicProofs/Spec.lean`: Pure shared definitions only (`module`, `public`, zero proofs, zero `sorry`; `12` core definitions pinned in `comparator.json`).
- `CellulogonicProofs/{StoichiometryThermo,MembraneGeometry,BioenergeticsEndosymbiosis,ChemiosmosisAutopoiesis,EutelicOrganogenesis,CytoskeletonNanomechanics,MorphogeneticGRN,ContinuumBiomechanics,NonVacuity,AdversarialTests}.lean`: **78** sorry-free machine-checked theorems (`T01`–`T58`, `C59`–`C62`, `NV01`–`NV08`, `AT01`–`AT08`).
- `Challenge.lean` ↔ `Solution.lean` ↔ `comparator.json`: Palomar isolated specification contract verified across all 6/6 kernels under `bubblewrap` in CI + live negative tamper rejection (`scripts/test_lean_negative.py`).
- Static interactive dependency blueprint generated by `scripts/build_blueprint.py` and deployed via `.github/workflows/pages.yml`.
