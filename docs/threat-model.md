# Threat Model (`docs/threat-model.md`)

STRIDE threat analysis for **CELLULOGONIC MECHA `v1.6.0`** covering the native C11 binary parser, local WebGL2 Observatory HTTP bridge, Lean 4 formal proof pipeline, and supply chain (Build Standard `B36`).

## 1. Trust Boundaries & Attack Surfaces

1. **Untrusted Binary Snapshot Input (`cellulogonic_load_snapshot()` in `src/abi_exports.c`):** Parsing `.cmbin` files from external collaborators or archives.
2. **Local HTTP Bridge (`web/server.mjs` on `127.0.0.1:8788`):** Browser cross-site request forgery (CSRF), oversized payloads, path traversal, or worker queue exhaustion from malicious browser tabs.
3. **Formal Proof Integrity (`lean/`):** Subtle `sorry`, `native_decide`, `autoImplicit` typo-generalization, or `Challenge`/`Solution` definition mismatch sneaking past review.
4. **Supply Chain & Secrets:** Third-party package compromise or accidental credential leaks.

## 2. STRIDE Matrix & Verified Mitigations

| STRIDE Threat | Concrete Scenario | Implemented Mitigation | Verification Artifact |
|---|---|---|---|
| **Tampering** | Crafted or bit-flipped `.cmbin` file injects impossible negative masses, overflowing `INT64_MAX` accumulators, genotype/phenotype desync, non-neural axons, invalid cell/bond indices, or trailing bytes. | `"CMB5"` format validates magic, ABI version (`0x00010600`), NIST FIPS 180-4 SHA-256 trailer, `MAX_LEDGER_ACCUM = 1e15`, explicit zeroed padding (`_Static_assert`, incl. dead organelle slots), genotype/phenotype sync, active-only bond/neural-only axon invariants, exact EOF, and `0 amu / 0 uq` ledger closure. | `G06` & `G25` tampered/re-signed & trailing-EOF rejection in `test/test_falsification.c`; dual-mode `test/fuzz_cmbin_abi.c` (1,000-case standalone + `libFuzzer` CI smoke); ASan/UBSan CI job. |
| **Spoofing / CSRF / DNS Rebinding** | Malicious website sends cross-origin `GET`, form `POST`, or DNS-rebound `Host` header to `http://127.0.0.1:8788` to reset or inject DNA into the local Observatory. | Loopback-only bind (`127.0.0.1`); exact-port `Host`/`Origin` check on ALL routes; mutating `GET` blocked with `405`; `POST /api/cmd` requires `Content-Type: application/json`, strict `Sec-Fetch-Site`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, and zero-`'unsafe-inline'` `CSP`. | `test/test_web_server.mjs` (`13/13` automated HTTP/CSP/CSRF/DNS-rebinding/favicon tests PASS). |
| **Denial of Service** | Flood of oversized HTTP bodies or concurrent simulation commands exhausts memory or deadlocks the C11 `stream` worker. | Immediate `413` socket destroy above byte limit; strict `400` URL parse guard; serialized FIFO queue with `429` backpressure cap; `0` post-warmup heap allocations in C11 core (`P10`, 3-module `nm` audit). | `G10` (`post_warmup_allocs == 0`); `web/server.mjs` queue cap. |
| **Information Disclosure** | Static file handler leaks arbitrary host files or `.git`/`.env` via `../` path traversal. | Explicit allowlist of served files (`index.html`, `styles.css`, `app.js`, `renderer3d.js`) + `204 /favicon.ico`; all other paths rejected; zero personal data collected (`personal_data: false`). | `web/server.mjs` static allowlist; SHA-256-verified `gitleaks 8.30.1` CI scan. |
| **Elevation / Formal Proof Spoofing** | A Lean theorem silently uses `sorryAx`, `native_decide`, `autoImplicit`, or alters a shared definition between spec and proof. | `autoImplicit = false`, `relaxedAutoImplicit = false`; pure `Spec.lean` (`12` pinned defs) shared by isolated `Challenge.lean` & `Solution.lean`; 6 independent kernels (`lean`, `leanchecker-paranoid`, `lean4lean`, `nanoda_bin`, `con-leche`, `con-ron`, `lake comparator --paranoid`); `check_readme_axioms.py`; live negative tamper rejection (`scripts/test_lean_negative.py` + CI sorry-tamper comparator gate). | `results/lean4-audit.txt`, `results/lean4-multi-kernel.txt`, `.github/workflows/ci.yml`. |
| **Supply Chain Compromise** | Malicious npm, PyPI, or C library dependency injected during build or execution. | **Zero external runtime dependencies** across C11, Node.js, Python (stdlib only), and Lean 4 (zero Mathlib); SHA-256 manifests (`CHECKSUMS.sha256`, `data/MANIFEST.sha256`), DigiCert RFC 3161 TSA, SHA-256-verified `osv-scanner 2.7.1`, and SLSA v4 `attest-build-provenance@v4` in CI. | `NOTICE`, `THIRD_PARTY_NOTICES.md`, `REUSE.toml`, `.github/workflows/ci.yml`. |
